# Behavioural ML

All data in this repository is **synthetic**: it comes from a simulator whose user model the authors wrote. The
numbers validate the pipeline (features, calibration, registry, serving), not real-world accuracy.

## Dataset

Generated by `simulator/dataset.py` from five personas × 8 seeds × 21 days
(`make train` regenerates it; `ml/datasets/synthetic/manifest.json` records the counts):

| File | Rows | Contents |
|---|---|---|
| `events.jsonl` | 17,368 | App opens/closes and focus events in the API schema |
| `sessions.csv` | 7,782 | Sessions with app, category, content label, "unwanted" flag |
| `risk_training.csv` | 23,798 | 23 features with three labels (distraction 0.322, doomscroll 0.206, continuation 0.454 positive rate) |
| `interventions.csv` | 968 | Logged actions with propensities for off-policy analysis |
| `content_captions.csv` | 4,800 | Captions across six content categories |

Splits are **grouped by `persona:seed`**, so no simulated user appears in both training and test; the test split
holds 5,144 rows from eight held-out user-seeds.

## Features (23)

Session (`session_minutes`, `previous_session_minutes`, `scroll_rate`), time (`hour_sin`, `hour_cos`, `is_night`,
`is_weekend`, `trigger_hour`), intent (`focus_active`, `in_restricted_window`), content
(`content_entertainment`, `content_productive`, `content_confidence`), app (`app_social`, `app_video`), load
(`opens_last_hour`, `daily_social_minutes`, `daily_limit_ratio`), history
(`avg_session_minutes_14d`, `long_session_rate_14d`, `override_rate_14d`, `accept_rate_14d`,
`minutes_since_last_intervention`). The same function computes features for training and serving, which removes a
common source of train/serve skew.

## Models and results (held-out test split)

| Target | Model | ROC-AUC | PR-AUC | Brier | ECE | Rules baseline ROC-AUC |
|---|---|---|---|---|---|---|
| distraction | XGBoost + isotonic calibration | **0.877** | 0.840 | 0.125 | **0.022** | 0.799 |
| doomscroll | LightGBM + isotonic | 0.634 | 0.317 | 0.170 | 0.030 | 0.573 |
| continuation | LightGBM + isotonic | 0.605 | 0.553 | 0.242 | 0.024 | 0.559 |

Content classification (TF-IDF + logistic regression): macro-F1 **0.948** against a 0.751 lexicon baseline.

**Honest reading**: only the distraction model is genuinely strong. Doomscroll prediction is weak (ROC-AUC 0.634,
and at a 0.5 threshold its F1 is 0.065 — it almost never fires), and continuation is barely better than the rules.
Calibration is good across all three, which matters because the decision ladder consumes probabilities, not labels.

## Serving

- `RiskScorer` blends interpretable logistic rules with the calibrated models (`RISK_ML_WEIGHT`, default 0.6) and
  always returns factors, so every score can be explained. A model failure is caught and degrades to rules.
- The registry (`ml/models/registry.json`) records versions, metrics and a SHA-256 for every artifact; files are
  verified before loading, and load errors are surfaced at `GET /api/models/status`.
- The evaluation reproduces the metrics **through the backend's own loaders**, so a registry or loader mistake
  shows up as a metric change.

## Reproduce

```bash
make train      # dataset + risk models + content model
make evaluate   # metrics and figures in ml/evaluation/reports/
```
