# Research question
Can personalized autonomous AI interventions reduce unwanted social-media consumption more effectively than static time limits while preserving user autonomy?

# Hypotheses
H1 adaptive interventions reduce unwanted sessions. H2 personalized policies outperform static limits. H3 goal-aware intervention improves adherence. H4 contextual-bandit personalization improves intervention success. H5 local-first processing improves perceived privacy.

# Evaluation
Baselines are no intervention, static screen-time limit, reminder-only and rule-based. Ablations remove memory, context, personalization or the bandit, or run rules only. Metrics include average social-media minutes, long-session frequency, unwanted sessions, goal adherence, override rate and simulated satisfaction. Results from the synthetic simulator are not evidence about real people; a consent-based pilot study is required for that.
